# 开发流程（通用规则）

> 适用于所有 AI 编程助手：Qoder、Trae、Cursor、Windsurf、Copilot 等。

## 核心原则

- **目标导向**：所有产出服务于用户最终目标。
- **闭环执行**：每个子任务走完「收集 → 计划 → 实现 → 测试 → 文档 → 验证」六步，禁止跳步留半成品。
- **自主决策**：可逆操作（编辑文件、运行测试、修复 lint、调整实现）直接执行不询问；不可逆/高风险操作才暂停。
- **透明沟通**：阶段开始一句话说明意图；关键节点简短更新；不复述内部思考；收尾直接输出总结，不询问"是否继续"或"是否提交"。

## 自主执行保障

初始确认固化后，以下机制保障长时间自主执行，避免反复中断：

1. **迭代间自动衔接**：迭代之间不询问"是否继续"，仅一句话说明"进入第 N 轮迭代，重点：…"。连续推进，不因单轮完成而暂停询问。
2. **计划自主执行**：初始确认（一次性确认目标、范围、验收标准、约束、测试要求）后，计划制定直接执行，不询问"是否按此计划执行"，直接进入实现。
3. **默认决策优先**：遇到歧义时，优先采用既有约定或合理默认值，标注"待用户复核"，不暂停；仅当影响验收标准或显著改变方向时才中断。
4. **错误自主恢复**：测试/lint/类型失败直接定位根因并修复；依赖缺失或环境问题先尝试 2 轮自救（安装、配置调整、缓存清理），仍失败才中断。
5. **需求自主调整**：初始确认范围内的小幅调整（补充测试用例、细化接口、修正明显笔误）可自主执行并记录；显著扩大范围才中断。

## 迭代循环

1. **收集**：每轮迭代始于信息收集，为后续计划提供输入。
   - 回顾前序迭代记录与遗留事项，识别已完成/未完成项、踩过的坑、待修复的回归。
   - 获取 CI/CD 执行结果；若失败，将修复任务纳入本轮计划。本地等价门禁（lint/类型检查/测试/覆盖率）一并纳入收集范围。
   - 根据本轮预期工作领域，查阅对应技能文档获取设计系统、代码模板与硬约束。
2. **计划**：研究既有模式；拆分子任务；优先复用现有抽象与技能文档；三处相似才考虑提取，不过早抽象。若收集阶段发现 CI/CD 失败，将修复任务列为高优先级子任务。
3. **实现**：遵守对应语言技能文档与既有风格；优先编辑现有文件；公共 API 须有完整类型签名与中文文档注释；不写未被要求的功能、不为未来预留扩展点。
4. **测试**：公共 API 配套测试，优先通过公共接口测试；测试须覆盖功能、性能、边界场景；失败时定位根因，不放宽断言或绕过覆盖率检查；覆盖率不得低于上一次的值。
5. **文档**：同步更新文档注释；有价值决策追加到 memory；不主动新建 `*.md` 文档。
6. **验证**：逐条对照验收标准；全套门禁通过（lint/类型检查/测试/覆盖率）；给出变更清单。

未达标准回「收集」继续；达标准进入下一轮或收尾。

## 暂停条件

仅以下情况中断找用户：

1. **歧义无法自决**：多种合理解读且无既有约定可循。
2. **高风险/不可逆**：删除非临时文件、重命名公共模块/包、`force-push`、`reset --hard`（工作区有未提交改动时）、`git clean -f`/`-fd`/`-fx`、修改 CI/git config、引入新依赖、修改工具链配置文件（.pre-commit-config.yaml/ruff.toml/pytest.ini/.coveragerc/pyrefly.toml/.bumpversion.toml/uv.toml）、修改规则文件。普通 commit/push 不属于此类。
3. **不可恢复的失败**：根因不在本仓库、需外部环境/权限配合、或两轮尝试仍无法定位。
4. **超出初始确认范围**：需显著扩大范围或改变方向。
5. **用户主动询问**。

可直接自决：测试/lint/类型错误修复、代码风格选择、文件编辑、运行校验命令、收尾总结输出、`git clean -fX`、`git stash`/`stash pop`、`git revert`、创建/切换分支、工作区干净时的 `reset --hard`。

## 沟通与工具

- 阶段切换一句话说明；完成子任务后一两句总结；阻塞时说明卡点与需求。
- 独立操作并行调用；维护任务进度；长命令后台运行。
- 文件操作用专用工具（Read/Edit/Write/Glob/Grep），不用 `cat`/`sed`/`grep`/`find`。
- 不用 emoji。

## 收尾

仅所有阶段交付后执行：输出总结（交付物、关键决策、遗留事项）→ 自动 `git add`（按文件名）+ `git commit`（遵循 Git 提交规则）+ `git push`（分支已跟踪远程时）→ 更新 memory。验收未满足则回「收集」继续，不停下询问。
