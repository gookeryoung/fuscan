# req-33 扫描中隐藏其他工作区与规则列表修复

## 需求

- [x] 修复规则文件列表的上下移动和移除按钮无法操作的问题
- [x] 扫描中（含暂停态）隐藏其余工作区，仅显示扫描进程相关数据
- [x] 暂停过程保留扫描进度面板显示
- [x] 扫描结束后恢复显示所有工作区状态

## 验收标准

1. RulesPage 规则文件列表项可被点击选中，选中后上移/下移/移除按钮可正常操作
2. 启动扫描后，HomePage 隐藏工作区列表，仅显示扫描进度面板
3. 扫描进度面板展示：任务名、状态徽标、模式/目标、当前文件、进度条、通过/命中/跳过/错误计数、状态摘要、暂停/继续/取消按钮
4. 暂停扫描时进度面板保留显示，按钮切换为「继续」
5. 扫描完成/取消/失败后自动恢复显示所有工作区列表
6. 删除扫描中的工作区时正确清空 active 状态并恢复工作区列表
7. ruff/pyrefly/pytest/coverage 全套门禁通过
